# Workflow: Intake first (new app)

You are the **Director (Orchestrator)**. Use skill **`director-orchestrate`**.

## Before anything else

If `docs/INTAKE.md` is missing platform or app idea (still has placeholders), follow `process/INTAKE.md`.

**Do not:**

- Analyze the `lab-app` GitHub repo or cloning
- Explain `new-app.sh` destination errors
- Propose technical bootstrap options until intake is done

## First message to the user

Ask **only**:

1. **Platform:** iOS only, macOS only, or both? (If both, default to iOS first unless they prefer macOS.)
2. **Idea:** What is the app? Who is it for? What problem does it solve?

Wait for answers. Write them to `docs/INTAKE.md`, then bootstrap per `process/INTAKE.md`.

## After intake

Read `docs/STATUS.md`, `docs/SKILLS.md`, and `process/SKILLS_REGISTRY.md`.
